# Страницы для регистрации приложения TikTok

TikTok требует при заведении приложения три адреса, и все три должны быть на
`https`. Две страницы лежат здесь, третий адрес отдаёт сама панель.

## Что куда

| Поле в TikTok for Developers | Что вписать |
|---|---|
| Terms of Service URL | `https://ВАШ-НИК.github.io/shorts-legal/terms.html` |
| Privacy Policy URL | `https://ВАШ-НИК.github.io/shorts-legal/privacy.html` |
| Redirect URI | `http://127.0.0.1:8000/api/accounts/tiktok/callback` |

Адрес возврата панель показывает на странице «Аккаунты» — там же кнопка
«Скопировать». Он работает без домена и туннеля, потому что **приложение
заводится с типом Desktop**: для этого типа TikTok разрешает `localhost` и
`127.0.0.1`. Если завести приложение как Web, потребуется внешний `https`, и
всё усложнится на пустом месте.

## Как выложить страницы бесплатно

1. Создать на GitHub публичный репозиторий, например `shorts-legal`.
2. Положить в него `terms.html` и `privacy.html` из этой папки.
3. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/root`.
4. Через минуту страницы откроются по адресам из таблицы выше.

Перед публикацией впишите в подвал обеих страниц свою почту — сейчас там стоит
напоминание вместо адреса.

## Порядок действий целиком

1. Выложить две страницы, получить их адреса.
2. TikTok for Developers → Manage apps → создать приложение, тип **Desktop**.
3. Вписать три адреса из таблицы.
4. Подключить продукт **Content Posting API**, запросить права
   `video.upload` (черновики) и `video.publish` (сразу в профиль).
5. Скопировать Client key и Client secret в `.env`:

   ```
   TIKTOK_CLIENT_KEY=...
   TIKTOK_CLIENT_SECRET=...
   ```

6. Перезапустить сервер, открыть «Аккаунты» → «Подключить TikTok».

## Чего ждать до аудита

Пока приложение не прошло проверку TikTok, действуют ограничения: публиковать
могут не больше пяти аккаунтов за сутки, и аккаунт должен быть приватным в
момент публикации. Режим «черновик» этих ограничений не касается — ролик просто
приходит во «Входящие» приложения, а публикуете вы сами.
